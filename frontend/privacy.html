Privacy information

What this Brew & Bean ordering website stores and uses.

Project status: this page describes the current website implementation. It is not legal advice or a substitute for a policy reviewed for the café operator’s location and service providers.

Information stored

When you register, the service stores your name, email address, optional phone number, and a one-way password hash in its configured MongoDB database. Orders store the account reference, order items and prices, contact details supplied at checkout, delivery address when delivery is selected, chosen payment method, totals, and order status. Passwords are not stored in plain text.

Browser storage

The cart is held in this browser’s local storage. A signed-in session token and basic account display information are also held in local storage so pages can use the account session. Signing out removes the session values; clearing browser storage removes the local cart.

Password recovery and payments

Password reset links use single-use tokens stored as hashes and expire after one hour. If an administrator configures SMTP, the reset link is sent through that mail provider; in development without SMTP, it is written to the server console. The current site records a selected payment method but does not process card or UPI payments through a payment gateway.

Questions

For questions about this demonstration website, contact hello@brewandbean.com. The production operator should replace this address and add verified data-retention, access, and jurisdiction details before public launch.
