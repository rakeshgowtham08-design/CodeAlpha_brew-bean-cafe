Ordering terms

How the current Brew & Bean ordering demonstration behaves.

Project status: these notes summarize the current application behavior. They are not a complete legal agreement; the café operator should add its legal identity, jurisdiction, consumer terms, and reviewed policies before production launch.

Menu and orders

Menu prices and availability may change. An order is recorded after the server validates the cart and creates an order record. The server calculates item totals, tax, and delivery fee; discounts are not currently offered. Available stock is reserved when a new order is placed, and an order is rejected if stock is insufficient.

Delivery and payment

The application supports standard delivery, express delivery, and café pickup. Payment choices are recorded with the order, but the current application does not charge cards or process UPI transactions. Do not enter payment card details into this website.

Order status

Order status is updated by an authorized administrator and shown on the signed-in customer’s tracking page. The current data model does not include cancellation or refund workflows.

Support

For questions about this demonstration website, contact hello@brewandbean.com. Replace this contact with the production operator’s verified support details before launch.
